# Security acceptance matrix

Release evidence must execute these against the production runtime role and resolved
Compose plan. A missing fixture or unsupported control is a failure, not a skip.

1. Cross-channel ingest/retrieve/traverse/synthesize/govern/export denial.
2. Membership removal during request, queued work, cached response and pack release.
3. Per-workload positive/negative operation and arbitrary-channel matrix.
4. NIP-98 duplicate, malformed binding, skew, wrong origin and cache-exhaustion cases.
5. Direct SQL RLS for every tenant table, edge and null-document node.
6. Effective secret ACL and rollback tests under real Windows principals.
7. Approved-CIDR success and outside-CIDR failure from separate hosts.
8. Bomb, polyglot, malformed, encrypted, huge-dimension and malware attachments.
9. Mandatory signed size/digest and exact object-key/digest mismatch cases.
10. Cross-format prompt injection with zero action/disclosure and complete citations.
11. Image/SBOM/vulnerability/signature/provenance verification and secure rollback.
12. Secret, auth proof, corpus content and cross-channel identifier log-leak scan.
